# 《高密机柜热失控紧急降额规范》

本规程适用于数据中心高密算力服务器机柜因局部气流短路、盲板脱落、风扇失效或计算过载引发的单点热失控突发事件。本规程涉及 IT 计算节点业务降额与紧急断电，须严格遵守审批流。

## 1. 局部热点成因定界

1. 定位超温机柜与 U 位：调取动环系统机柜前后门三点测温传感器数据（上、中、下位），确认进风温度是否超过 32℃，出风温度是否突破 45℃。
2. 排查盲板气流短路：现场核验机柜空置 U 位是否完整安装阻隔盲板，检查是否存在热风从机柜侧面或顶部向冷通道回流倒灌现象。
3. 检查机柜背板与服务器风扇：核查目标机柜背板散热风扇单元转速反馈，检查机柜内刀片服务器风扇是否存在 PWM 调速锁死或停转告警。
4. 关联 IT 功耗与利用率：调取服务器带外 BMC 与 Prometheus 性能监控，检查 CPU 利用率是否持续 100%、单机柜总功耗是否突破 8kW 设计上限。

## 2. 临时控温补偿

1. 开启机柜下送风风口调节：调节超温机柜底部高架地板送风散流器开度至最大（100% 全开），提升静压箱送风量。
2. 增设临时移动导风板：在冷通道入口部署活动导风板，引导冷气流集中吹向超温机柜进风面。
3. 调低机房局部送风静压箱风门：联动控制附近精密空调加压送风，增加机房地板下静压 5~10 Pa，加速热风排出。
4. 隔离冷热通道物理门禁：检查冷通道密封隔断移门是否完全闭合，避免外部未受控气流扰乱冷池风场。

## 3. 服务器紧急降频与下电顺序（高危）

> [!CAUTION]
> 本步骤包含高危 IT 操作，直接影响线上算力服务，温升超过临界保护值时方可触发，并需记录操作审计日志。

1. 业务算力动态降频：通过带外 IPMI/Redfish 接口下发功耗上限指令（Power Capping），将目标机柜内服务器 CPU 频率限制在 50%~70%，抑制功耗输出。
2. 迁移非关键业务容器：协同容器编排调度平台（如 K8s），将该机柜内非核心批处理任务及无状态微服务平滑驱逐至其他空闲温区机柜。
3. 临界温升软关机（高危）：若经上述降频 5 分钟后机柜进风口温度仍高于 45℃ 或 CPU 结温达到 95℃ 节流阈值，按业务依赖顺序执行服务器平滑软关机（`systemctl poweroff`）。
4. 物理紧急下电与断路器隔离：若发生服务器机箱冒烟、主板烧蚀等极端火警隐患，立即拉下机柜对应 PDU 支路空气开关断电，启动火警应急响应。
